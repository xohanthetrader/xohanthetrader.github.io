Multisets as Pure Functions

What are Multisets

Before discussing Multisets there are a few properties of the objects they are based on, Sets, I want to recall. For the purposes of discussion here we will assume we are working within some nice wider thoery and as such we arent concerned with constructing some theory of sets fit for purposes/

Sets

Sets are collections of objects where order and the count of occurences of objects dont matter. The way this is acheived is with the binary predicate \(\in\) and The estensionality axiom. \(\in\) is the principle way of interacting with a set and all of its other operations are built up from here. If we have the proposition \(x \in X\) where \(X\) is a set and \(x\) is some kind of object, this proposition being true corresponds to \(x\) being contained in the set \(X\). As such we cant tell how many times it occurs or where it occurs. As such this is what gives us the notion of equality for two sets

Axiom 1 (Extenionality). \(\forall X \forall Y \left[ X = Y \iff \forall a (a \in X \iff a \in Y) \right]\)

Where we consider \(X,Y\) to be quantified over sets and \(a\) is to be quanitified over whatever objects you care about. The Axiom of Extensionality then tells us equality of two sets are given extensionally and as we can only interact with sets with the \(\in\) predicate we are unablle to diffrentiate between sets by the count of certain elements nor the order of certain elements. As cuh the following equalites are something that hold for sets \[\left\{ 1,1,2 \right\} = \left\{ 1,2,1 \right\} = \left\{ 1,2 \right\} = \left\{ 2,1 \right\}\] Other things about sets are to be as normal. I just wanted to draw attention to the equality.

Multisets

In order to avoid basically leading the question and to focus on the connection to sets im going to give a nonstandard presentation of multisets. the difference between a multiset is that they care about how many toimes an element occures withing them, i.e. elements have a given muliplicty. As such we want to encode this in the predicate. First we need to have a set of objects we can refer to to encode the count of an object. For this we use the set \(\mathbb{N}\) of natural numbers. Our predicate here is a trinary predicate \(\bar{\mu}\). If we conseider the proposition \(\bar{\mu}(x,n,X)\) where \(x\) is an object, \(n \in \mathbb{N}\) and \(X\) is a multiset we interpret thecose in which this poropistion is true as the statement that \(x\) occurs within the multiset \(X\) \(n\) times. For example the follwing are true for mulitsets written in the traditional set notations

  • \(\bar{\mu}(1,2,\left\{ 1,1,2 \right\})\)

  • \(\bar{\mu}(2,1,\left\{ 1,1,2 \right\})\)

  • \(\bar{\mu}(3,0,\left\{ 1,1,2 \right\})\)

And the following false

  • \(\bar{\mu}(1,3,\left\{ 1,1,2 \right\})\)

  • \(\bar{\mu}(2,0,\left\{ 1,1,2 \right\})\)

  • \(\bar{\mu}(3,1,\left\{ 1,1,2 \right\})\)

Now a problem arrises in the case where we have \(n,m \in \mathbb{N}\) and \(n \neq m\) but we have both \(\bar{\mu}(x,n,X)\) and \(\bar{\mu}(x,m,X)\) hold at the same time. The problem is we have an indeterminate multiplicity. A similar problem happens if we have no \(n\) for which this porporsition is true. As such I intorduce the following axiom for multisets.

Axiom 2 (Determinacy). \(\forall X \forall x \exists ! n \in \mathbb{N} [\bar{\mu}(x,n,X)]\)

As such we have that there is only one multiplicity for each eelemnt and it must have a multiplicity (a multiplicity of zero is analogous to an element not occuring). As such we can use this similarly to develop an extensionality axiom.

Axiom 3 (Extensionality).
\[\forall X \forall Y \left[ X = Y \iff \forall a \forall n \in \mathbb{N} (\bar{\mu}(a,n,X) \iff \bar{\mu}(a,n,Y)) \right]\]

This is similar to the extensionality axiom for sets where die to the fact that \(\bar{\mu}\) is the only way to determin information about multisets. If two multisets are exyensionally the same under \(\bar{\mu}\) then they must be the same multiset. Combinig this with the axiom of Determinacy we have that two multisets are equal if the mulitplicity of each element is the same in each irregardless of the ordering. As such for multisets the following equalities qwould be true \[\left\{ 1,1,2 \right\} = \left\{ 1,2,1 \right\} \neq \left\{ 1,2 \right\} = \left\{ 2,1 \right\}\]
